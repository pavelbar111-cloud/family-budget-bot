# Семейный бюджет — Telegram-бот

Бот для учёта доходов и расходов Паши и Тани.

## Что умеет

- Принимает текст: `Еда магазины 4500`, `Паша ЗП 136000`
- Принимает скриншоты из банка (через OpenRouter)
- Автоматически определяет категорию или спрашивает кнопками
- Пишет всё в Google Таблицу
- Удаляет последнюю запись (`/удалить`)
- Делает отчёты (`/отчет`, `/отчет_прошлый` и т.д.)
- Каждый день в **17:00 по Москве** присылает напоминание

---

## Как запустить (самый простой способ для новичка)

### Вариант А — через Railway (рекомендую)

1. Зайди на [https://railway.app](https://railway.app) и зарегистрируйся через GitHub.
2. Нажми **New Project** → **Deploy from GitHub repo** (или Empty Project + Upload).
3. Загрузи все файлы из этой папки.
4. В настройках проекта добавь переменные окружения (Variables):
   - `BOT_TOKEN` = твой токен бота
   - `OPENROUTER_API_KEY` = ключ OpenRouter
   - `SPREADSHEET_ID` = ID таблицы
5. В Root Directory укажи папку с ботом.
6. Deploy.

Бот будет работать 24/7.

### Вариант Б — на своём компьютере (для теста)

1. Установи Python 3.10+ с сайта python.org
2. Открой командную строку в папке с ботом
3. Выполни:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
4. Оставь окно открытым — пока оно открыто, бот работает.

## Важно перед первым запуском

1. Убедись, что Google Таблица расшарена на email:
   `budget-bot@family-budget-bot-505507.iam.gserviceaccount.com`
   (права «Редактор»)

2. Добавь бота в группу (если будете писать в группе):
   - Найди своего бота в Telegram
   - Добавь его в группу
   - Сделай его администратором (хотя бы с правом читать сообщения) **или** отключи Privacy Mode через BotFather (`/setprivacy` → Disable)

3. Напиши боту `/start` в личку и в группе.

---

## Команды бота

- `/start` — приветствие
- `/помощь` — справка
- `/отчет` — текущий месяц
- `/отчет_прошлый` — прошлый месяц
- `/отчет_квартал` — квартал
- `/отчет_год` — год
- `/удалить` — удалить последнюю запись

---

## Структура Google Таблицы

Бот автоматически создаст лист **«Транзакции»** с колонками:

| Дата | Время | Кто | Тип | Категория | Сумма | Описание | Источник | MessageID |

Лист **«2026»** можно потом сделать сводкой с формулами по образцу твоего Excel.
